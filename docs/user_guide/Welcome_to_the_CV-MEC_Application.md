# Welcome to the CV-MEC Application
The CV-MEC application allows users to to test various 5G V2X technologies using the Verizon ETX cloud message routing system. The CV-MEC application features the ability to encode and decode J2735 ASN.1 messages including BSM, SPaT, MAP, TIM, PSM and SDSM. The app has been demonstrated at numerous events including the Wyoming Connected Vehicle Interoperability, the 5gaa technologies demonstration at Turner-Fairbank Highway Research Center, and ITS World Congress 2025.

The CV-MEC applications offers two types of sessions, [Vehicle](<Vehicle_Preferences_User_Guide.md>) or [Pedestrian](<Pedestrtian_Preferences_User_Guide.md>). Based off the option selected, users can interact with the map and technologies incorporated in the MAP.

# Changelog
## Version 69
Plugfest Test Release
New Features
    - Added Support for sending Signed Messages using ISS SDK
    - Added Support for connecting to ISS MQTT Broker
    - Refactored MQTT Broker system to use common logic for greater future extensibility

## Version 59
ITSWC Release Version
New Features
    - Adds support for PSM 
    - Adds data structures for SRM
    - Adds data structures for SSM
    - Adds ability to connect to an OBD-II Bluetooth sensor
    - Added ability to connect to Ettifos OBU for GPS
    - Added ability to connect to Ettifos OBU for PC5 Message forwarding
    - Added ability to pull GPS data stream from CradlePoint Message router
    - Added Support for Linux

## Version 34
5GAA Release
New Features
    - Added Support for Receiving SPaT Messages
    - Added Support for Receiving MAP Messages
    - Added Countdown to Green Graphic
    - Fixed Time Synchronization Issues by forcing CV-MEC to always use AWS NTP Time Server

## Release 26
Interoperability Release
New Features
    - Added integrated system for encoding and decoding ASN.1 messages
    - Added Support for transmitting BSM messages
    - Added Support for Receiving BSM Messages
    - Added Support for Receiving Tim Messages


## Release 12
First delivered release of the CV-MEC application to Leidos. Added ability to connect to Verizon IMP Service and Log Message Latencies.
